# Linux Starter: read-only Standard → Dugout Base review

The actual closed first Standard Base menu can open a cancellable review of a
native Dugout Base Season 2 draft. The worker reads only its own exact Starter
slot and uses the shared CP299 native projection, including strict restore
of the actual destination. The parent receives only fixed hashes on its live
pipe, not a save, snapshot or write token. This is not a title unlock or a
Start action; the current Standard slot remains exactly where it was.

Use the official pinned no-env Linux Starter pair, with its matching adjacent
PCK and the exact generated CP170 closed fixture (never a player slot):

```sh
python3 tools/qa/cp300_starter_dugout_review/check_worker.py "$ELF" "$CP170_CLOSED"
```

For rendered validation, use an independent no-env isolated Starter profile.
Continue, press Review, verify Cancel is visible while pending, cancel and
wait for byte-inert return. Review afresh and expect the verified no-save
notice with no action to Start Dugout. Exact primary and backup, if present,
must not change and there must be no temp save. Ordinary Next remains the
existing separate control. Do not click it during this smoke.
