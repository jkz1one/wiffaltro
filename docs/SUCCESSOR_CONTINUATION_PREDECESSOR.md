# Closed terminal112 predecessor projection

This is a read-only prerequisite, not a new persistent owner, migration, run 2
birth or permission to grant assets. Its positive terminal path remains
unqualified until the actual owned full-season test completes.

## Authority boundary

The only accepted source family is the existing exact Owner112 envelope. Cheap
checks may reject clearly active/foreign candidates, but serialized terminal
labels never authorize success. Any returned projection must pass the complete
frozen Owner112 Codec restore, exact runtime/career types and scope, COMPLETE
phase, one completed run with original current=1, empty pending jobs and consumed
physical reports. Existing settlement is rechecked and the nonempty original
asset journal is reconstructed through the existing asset basis/from_data path.
The derived ledger must match the original serialized ledger exactly.

After those derivations, full recapture must still match both the archived input
and the caller's envelope. The detached result contains the exact old envelope,
source provenance, completed row/receipt, assets/pennants/plaques and derived
income/progress/awards/earned/owned/policy. It contains no live ledger object.

There is no generic accepted-hash list, substitute partial authored identity,
caller-supplied validated SeasonState or saved trust flag. A later owner must
rerun the reader against the retained envelope; a serialized projection is not
proof. Frozen close()/start() methods and current=1 are never changed or invoked
as a shortcut, and the existing wallet is never replaced with a fresh one.

## Current test boundary

The negative suite uses immutable generated evidence from the real Owner112
full-season run: its actual birth and its progressed active ninth-human boundary.
It fully restores the original birth under the old reader, rejects both active
states as predecessors, rejects a forged terminal label on the birth, and rejects
unknown source/catalog/format/version, rewritten current and standalone-shaped
inputs. Original input bytes, held authored Resources, all existing save files
and the frozen descriptor remain unchanged. This negative suite passes in two
separate fresh processes. The progressed active case is a
cheap rejection, not another complete replay of its long history.

The test includes an explicit completed-input mode for later actual terminal
qualification, but that mode has not run. No synthetic completed row substitutes
for physical completion. Positive detached-result correspondence, original
awards/access preservation, new owned run 2 draft/round/shop, atomic transition,
retry idempotence and cold continuation remain required. This prerequisite does
not claim that career continuation or Dynasty works.
