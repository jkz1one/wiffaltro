# Closed-prefix exotic-history prerequisite

The additive `successor-career-history-v1` helper is a pure legacy Game109
history branch for future persistent-career integration. It does not change
Game109's currently empty inherited-start admission, install an entitlement,
start a run, migrate a save, or grant a recipe/cash. A new gameplay/owner family
must still validate its own current-catalog branch and fully replay prior owners.

`collect(runs, before_run)` validates only the explicitly selected closed prefix.
Completed and abandoned rows must satisfy original receipt/league/tier policy,
strict successor progress and seed/catalog binding. An active prefix is rejected;
the target and suffix are not admitted or validated as ownership. Invalid is
explicitly distinct from a valid empty prefix. Returned proofs are detached.

`evaluate(proofs)` preserves bounded proof lists, including legitimate repeated
seeds, and unions sorted eligibility IDs using unchanged per-proof thresholds.
It never pools incomplete counters across seasons. Prices remain those of the
frozen Game109 offerings. This is structural consistency, not physical provenance.

The test strictly restores the isolated actual112 paid-round fixture first. It
checks exclusion of the active run, explicit prefix boundaries, deep-copy and
save immutability, malformed/mixed-catalog rejection and original price parity.
A relabeled abandoned row and curve threshold operands are explicitly synthetic
policy inputs only. They do not establish a played closure or completed career,
and no owner or save receives those synthetic operands.

Godot 4.6.3 passed this suite in a fresh isolated project on2026-11-17, with no
script errors. Original fixture bytes and reconstructed owner data were unchanged.
Manifest bytes/hashes, Python compilation and diff whitespace checks passed.
This prerequisite alone is not next-season carryover or Dynasty verification.
