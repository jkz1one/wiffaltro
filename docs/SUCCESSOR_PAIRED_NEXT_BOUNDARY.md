# Private Base Doubleheader: Next proposal boundary

This checkpoint freezes a same-league, Base-tier ordinal-two proposal on the
exact first closed standalone owner. The existing ordinary payload remains the
current, complete archive. A proposal changes only the ordinary owner's
proposal field; the close receipt, career balance, original results, physical
proofs, and dormant-mode metadata remain in place. Original ordinary session
bytes are exact. The unchanged writer may encode hydrated whole integers in
the outer receipt and aggregate with a .0 suffix; their values must agree
exactly, and the previous complete byte stream is the immediate backup. Fresh reopen authenticates
the full season and original close before accepting the exact proposed source,
seed, ordinal, league, tier, and native earned start. A held write is pinned
separately to the active owner and disk and cannot change the proposed seed.

This is not a new-season save or migration. Next commit, any new gameplay,
public selection, other tiers, and Dynasty remain closed. Commit must move the
validated completed ordinary payload and exact close provenance into a flat
first-season archive before starting the new authored paired draft. A digest
or a backup file is not archive authority; cold admission must authenticate
that archive and derive the new start again. No recursive owner snapshots.
Later rollover will need a separately qualified bounded, ordered archive of
season-native checkpoints and folds rather than assuming this first proposal
supports arbitrary ordinals.

## Resume and settle the opening leg

The same private flag now exposes **Resume Opening Doubleheader Leg**
only at the exact first-leg pending stage. Each press starts at most one
native bound NPC fixture (1 then 2); the next press settles the opening
leg. Each actual report is checkpointed independently, and the menu
reports how many are saved. No action replays the human game or lets
opening-leg controls launch the return leg.

one normal game reward per club, with no first-leg sweep bonus. It
preserves the exact first-leg workload used to derive the reversed
return fixture's stamina debt. The authored rules allow a shop between legs, but
its UI and the actual second human leg remain held in this slice.
