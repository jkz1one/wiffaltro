## Mechanics that must survive integration

- Five paired regular-season rounds: thirty fixtures, reversed return venues,
  then ordinary playoffs. Each leg settles separately and permits its own shop.
- Existing candidate six-Cash sweep bonus only on the qualifying second reward.
- Identity-based debt from exact first-leg releases minus validated refunds and
  recovery. Capacity changes cannot erase debt; new pairs/playoffs reset it.
- Per-game counts, finished flags and tactical-use limits reset normally. No new
  injury or mandatory rotation policy is invented.
- Exact Gear use and sale history survives between-leg purchases/replacements.
