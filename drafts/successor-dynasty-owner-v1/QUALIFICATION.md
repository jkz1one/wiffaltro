# Dynasty owner: first bounded engineering gate

This inactive additive family is not a finished Dynasty mode or a public unlock.
The ordinary launcher remains on the verified 119 route. Original saves, frozen
source families, visuals, and the earlier five-file adapter draft remain intact.

## Boundary

- Explicit development-only fresh Dynasty constructor, authored four-pick draft,
  concrete human and all five AI build/development factories, six versioned start
  profiles, and current physical request bindings.
- Materialized current-season consistency checks, not cryptographic or historical
  anticheat proof. One current row; no recursive predecessor or unlimited season
  history. Separate `user://wiffaltro-dynasty-owner-v1.json` slot.
- Optional explicitly imported 119 snapshot retained separately, never written
  back to its original slot. Import preservation is not pause/resume gameplay.
- Profile contract retains authored floors/capacity, active and remembered inactive
  mastery, trained/catch-up components, learning and ability receipts, exotic
  acquisition rights and stable identities. Provisional paid-first two-stat/one-
  mastery decay helpers are not exposed as a completed transition lifecycle.
- JSON rule dictionaries are validated and normalized to their canonical integral
  representation on this reader only. Legacy ordinary-only guards are unchanged.
- Private catalog identity and authored-profile caches return detached copies.
  They do not cache mutable profile admission; current state remains validated.

## Tests and measured evidence

All harness modes require `WIFFALTRO_ISOLATED_TEST=1` before any save-slot
read/write. Cold mode refuses any owner without four completed picks, before the
choice loop; it cannot complete an unfinished draft.

`tests/successor_dynasty_owner_first.tscn` creates seed 91743, saves genuine birth,
performs all four actual draft choices, saves/reads each, checks all six profile
owner bindings, and constructs an actual match/physical request. Run again in a
separate process with `-- cold` to verify unchanged raw bytes and malformed
rule/profile refusals. `-- cold extras` additionally mutates returned cache copies
and checks strict import/capture/restore of a genuine 119 fixture supplied only as
`user://import119.json`. Fixtures and logs are private, not source attachments.

## Not qualified by this gate

No actual Dynasty physical game has completed/settled in this family. Pending
projection, paid shop/earned progression, terminal awards, natural/abandon once-
only transition, overflow choices, re-signing retained identity, alternate-league
activation/pause/resume, and visual playtesting require the following increments
in this same family. Current first-season validation deliberately rejects later
ordinals. No replacement cadence, entitlement, price, unlock threshold or final
character tuning has been invented. No distributable or completed Dynasty claim.
