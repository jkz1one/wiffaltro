# One generalized successor engine family: Phase A

Additive clone of the 37 frozen Game109 engine files, retargeted into
`successor_league_general_v2`. Game/build/development envelope identity114 and
report identity114 are separate from109. Recipe provider, recipe data and pitch
catalog version7 remain unchanged; the new purpose/source signature includes its
own closure and the retained legacy109 source dependency. No old source or save
is rewritten, upgraded or implicitly admitted.

## Structural context work

- Bare Standard keeps original Build41, original d1 pricing42 (also the original
  d2 build economy), d3 sponsor43 and d4 sponsor44 through inherited initializers.
  These have no `league_rules` header. There is no invented Standard tier profile.
- Explicit normalized League profiles retain original45/46 headers, original
  LeagueRules/tier-economy/bank/shop policies. The nine League registry IDs are
  engine operands, not proof of availability or career admission.
- Scramble calls original SeasonDevelopment initialization and its unchanged
  seed-based SeasonScramble stat permutation.
- Fresh EMPTY Dynasty initialization calls original policy. Nonempty carried
  Dynasty profiles are deliberately rejected: they need a new catalog-aware
  profile/owner/lineage adapter. No carry data is silently dropped or relabeled.
- Inherited exotic history is bounded and each proof must pass either the frozen
  legacy109 helper or this family's current Eligibility validator. Prices and
  thresholds stay unchanged. IDs are a sorted union of eligibility computed per
  proof; repeated seeds remain legal and partial counters are never pooled.
  Pristine installation deep-copies proofs. Build and development serialization
  and restore now retain those proofs instead of dropping the formerly empty
  `exotic_start` field. This remains a structural operand, not an earned grant.
- Current nonempty standalone development evidence remains inadmissible without
  the original full Build reward replay. Ordinary transaction replay is retained.

## Admission deliberately closed

Public new Runtime constructors return null; Codec.scope/envelope_valid return
false. ALL Game114 season/owner/save admission remains closed, including Dugout.
The copied internal replay/physical branches still carry narrow legacy-era gates
and are not claimed as validated generalized gameplay. Report114 is reserved for
this family and does not admit old reports under a new label.
